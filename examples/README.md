## Examples for integrations with LinkMobile
- iOS
- React Native

### React Native
The React Native example is a simple example of how to integrate LinkMobile into a React Native app. It can be found in the `examples/ReactNative/TimeKeeper+LinkMobile` directory.

Note: This example is not a complete app, it is only an example of how to integrate LinkMobile into a React Native app. If you desire to run this example, you will need to copy the `bridge-1.5.1.xcframework` and `LinkMobile-1.5.1.xcframework` files into the project's ios/ folder.

View the `LINKMOBILE_INTEGRATION.md` file for more information on how to integrate LinkMobile into a React Native app.
