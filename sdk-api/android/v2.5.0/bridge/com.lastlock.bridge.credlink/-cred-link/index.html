CredLink

class CredLink(blueLink: BlueLink, networkConnectivityMonitor: NetworkConnectivityMonitor, keyStoreHelper: KeyStoreHelper) : DefaultLifecycleObserver, ConnectivityListener

Public Interface that exposes various functionalities for performing BLE Credential Exchange operations with nearby Last Lock devices. Implementor must link BlueLink delegates for proper functioning of the package

Note:

  • The library assumes that peripherals on which operations are performed come are tracked in BlueLink

  • Any errors thrown by BlueLink will be sent to the implementor to handle aka CredLink library does not do any deep error handling caused by a violation of the assumptions specified above
