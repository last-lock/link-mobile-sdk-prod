CredLinkCryptoHandler

interface CredLinkCryptoHandler

Platform-native CredLink cryptography and key material handling. Android uses Keystore + BouncyCastle; iOS uses CryptoKit + Keychain via Swift adapters.

Implementations produce PKOC wire payloads only; CredLinkExchangeStateMachine performs GATT writes.
