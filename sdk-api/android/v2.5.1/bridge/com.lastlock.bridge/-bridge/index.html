Bridge

object Bridge : IBridge

The entry point for the SDK meant to initialize the SDK, scan and connect to nearby devices over BLE as well as perform credential exchange operations and create proxy network in the background for the locks to connect to the cloud. Note, Bridge and its implementation is designed to be asynchronous delivering results via delegates / callbacks.

Usage:

  • Retrieve instances of BlueLink, BLEProxy, DFUService, CredLink, etc. via the IsolatedKoinContext singleton.

  • Use this object to initialize the library, start scanning, and perform other integration tasks.

  • All dependencies are managed through Koin, ensuring isolated and safe access to library components.

Typical flow:

  1. Call init with your application context and server address to initialize the library.

  2. Use start to begin the foreground service to run blueLink and bleProxy.

  3. Use getBlueLink, getCredLink, etc. to retrieve library instances as needed.
