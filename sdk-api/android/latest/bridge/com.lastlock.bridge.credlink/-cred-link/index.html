CredLink

class CredLink(blueLink: BlueLink, networkConnectivityMonitor: NetworkConnectivityMonitor, iOSCryptoHandler: CredLinkCryptoHandler? = null, iOSTrueTimeManager: ITrueTimeManager? = null) : ConnectivityListener

Shared CredLink orchestration for PKOC credential exchange and offline time sync over BlueLink.

Responsibilities:

  • Session lifecycle (onSessionStart, onSessionEnd) and phone key management (validateLegacyPhoneKeys)

  • Queuing BlueLink operations and per-device timeouts

  • Thread-safe device registry and coordination with the internal exchange state machine

Platform cryptography is delegated to CredLinkCryptoHandler (Android Keystore + BouncyCastle, or iOS CryptoKit + Keychain via Swift).
